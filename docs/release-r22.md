# r22 · 管理面板刷新位置修复

## 更新与优化

- 修复管理面板每 2 秒自动刷新时页面上下跳动的问题。刷新前记录当前可见的票池或对话卡片，刷新后恢复同一张卡片在视口中的位置，不再把用户正在查看的内容推回顶部。
- 票池和对话卡片增加稳定的页面锚点，并关闭浏览器对动态卡片区域的自动滚动锚定，避免倒计时、请求状态和诊断文字变化互相抢占滚动位置。
- 保留票池卡片的展开状态、对话卡片的展开状态和已有请求明细；仅调整页面展示位置，不修改请求、节点、票据或采集策略。
- 本版本暂不修改压缩请求的票据处理和响应模型判断逻辑。

## 验证

- `node --check internal/service/web/app.js` 与 `node --check internal/service/web/traffic.js` 通过。
- `git diff --check` 与 `go test ./...` 通过。
- 在仅使用回环合成数据的浏览器夹具中，分别在票池区域和对话卡片区域等待多个自动刷新周期；`scrollY` 及当前可见卡片相对视口位置保持不变。
- 浏览器验收不包含真实上游请求或真实节点稳定性结论。

## 下载与升级

发布文件均以 `ccodex-sleep-state-r22-` 开头，覆盖 Mac Apple Silicon / Intel、Windows AMD64 / ARM64，并附源码包及 SHA256 校验文件。包内带版本、源码提交和更新说明，不包含维护者节点、订阅、票、凭据、口令或运行日志。

停止旧服务后替换程序，保留自己的配置与数据，再通过 start.cmd / start.command 启动；升级后刷新管理面板。
