# r19 · Codex 自动审批模型兼容

## 修复与优化

- 修复自动审批返回 `unsupported_model`：保留主会话 Astra / Sol / Terra 的票管理范围，同时识别 Codex 专用的 `codex-auto-review` 请求并按原模型转发。
- 审批请求不注入主票或备用票、不触发采集、不消费节点的采集轮次，不更换主会话模型或改动已有票。客户端附带的聊天 state 不会混入审批路由。
- 审批的请求正文、策略内容、上游决定、响应正文和 HTTP 错误原样传递；本程序不批准操作、不修改审批策略、不执行被拒绝的命令，也不自动重试请求。
- 审批与聊天的本地限流记录分开处理；上游认证与权限检查照常执行。已停用/失败节点仍不可用，使用过的采集节点可继续承载正常审批流量。
- 最近请求明确显示「自动审批」和实际请求/响应模型；三张主会话卡片继续只显示 Astra / Sol / Terra。
- 发布文件与包内版本更新为 r19，继续提供 Mac / Windows 四种架构、源码包、SHA256 校验文件和逐项更新说明。

## 验证范围

本地模拟上游验证：普通、gzip、zstd 审批请求的正文和模型保持；拒绝决定完整返回；401/403/429/503 等状态不被改写或重放；原主备票、采集节点状态与聊天限流记录不变；停用节点与认证检查仍生效；面板请求记录正确分类。

执行 Go 全量测试、gateway/service 竞态测试、go vet、网页/打包语法及发布包内容检查。Mac ARM 版在本机运行验证；Windows 与 Intel Mac 为交叉编译包。

本次不代替原任务执行被拒绝的命令。升级后，原任务仍需走正常审批流程；请求转发成功不代表审批结果一定为允许。

## 下载与升级

完整解压适配电脑的 `ccodex-sleep-state-r19-<系统>-<架构>` 文件，使用 start.cmd / start.command。升级前停止旧进程，保留个人配置与数据。所有发布附件带版本号，不包含维护者的节点、订阅、票、口令或日志。
