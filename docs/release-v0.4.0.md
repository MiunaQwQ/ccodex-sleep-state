# v0.4.0：一键检查、固定可用 state 与可控代理池

## 普通用户怎么开始

1. 下载对应系统的完整包并解压。Windows 双击 `start.cmd`；macOS 双击 `start.command`。
2. 首页先点 **一键检测环境配置**。有问题时点“带我去处理”，不用先研究高级参数。
3. 确认显示 Codex 已接管，重启 Codex、新建会话后再使用。

| 设备 | 下载文件 |
| --- | --- |
| Windows x64 | `ccodex-sleep-state-windows-amd64.zip` |
| Windows ARM64 | `ccodex-sleep-state-windows-arm64.zip` |
| Apple 芯片 Mac（M 系列） | `ccodex-sleep-state-darwin-arm64.tar.gz` |
| Intel Mac | `ccodex-sleep-state-darwin-amd64.tar.gz` |

同时提供含依赖的源码包及 `SHA256SUMS`。请保留包内的启动脚本和教程，不要只拷贝程序。

## 本次更新

- **一键检测环境配置**：只读检查本地配置和现有连接状态，问题优先显示并给出下一步。不读登录凭据、不下载订阅、不探测代理、不自动调用模型。
- **拿到后固定使用**：新用户默认固定主用，失效或发现不匹配后再获取。也可选择提前准备备用；切换策略保留已有主用/备用和冷却。旧配置缺少策略字段时保留旧模式，不强制切换。
- **手动输入与 TXT 多订阅导入**：每行一个订阅，合并去重，支持追加或替换。导入页默认勾选随机出口＋用后移出，追加时保留已有固定出口；不想改变策略可取消勾选。
- **可用、已用、失败、停用清单**：全选、手动回收、可恢复清理和单节点短探测。不在后台自动把失败节点放回。
- **出口单独设置**：正式请求可以用固定节点或独立随机节点；不要求与采集节点相同。不同节点配置不保证有不同公网 IP，跨出口 state 仍属实验功能。
- **本地 413 修复**：请求体、zstd 窗口、压缩回复上限默认 64 MiB，可在高级设置调整到 16–128 MiB。保留并发和解压边界，不提高上游限制。
- **中转助手**：规范地址、查询 Astra / Sol / Terra 模型列表、带备份补全缺失 `base_url`。不覆盖已有地址，不保存临时检测 key，不对中转强制采集 292。
- 补充朋友卡网展示、贡献元数据说明、合规边界和回退教程。

## 升级与回退

先正常停止旧服务，等正在运行的请求结束及配置恢复；保留旧程序和整个服务数据目录的私有备份，再解压新包。不要让两个版本同时接管同一份 Codex 配置。

新配置字段不能直接交给旧版本读取。需要回退时，先正常停止新版本并完成恢复，再恢复升级前的服务配置备份；不覆盖用户在测试期间另行修改的 Codex 配置。配置备份可能含订阅凭据，不要公开分享。更详细的步骤见[升级指南](upgrade-0.4.0-preview.md)。
